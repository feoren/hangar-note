# Hangar Note

A desktop app for notes, part of the Hangar family. It works next to the
[Hangar](https://github.com/feoren/hangar) desktop app.

**Status:** early planning. There is no code and no release yet; scope and non-goals are being
settled in the first design decision under [`docs/wiki`](docs/wiki/index.md).

## Planned platforms

- Windows 10 1809+ and Windows 11 (x64) first
- macOS 13+ (Apple silicon and Intel) and Linux x64 (X11 and Wayland) later

## Built with

Tauri 2 (Rust) with React, TypeScript and Vite.
